Rangkuman 4 Tenses

1. Present Simple Tense

(+) S + V1 (+s/es untuk He/She/It)
(-) S + do/does + not + V1
(?) Do/Does + S + V1 ?
(Wh) Where/What/When... + do/does + S + V1 ?
Time marker: always, usually, often, sometimes, every day, on Mondays.

2. Present Continuous Tense

(+) S + am/is/are + V-ing
(-) S + am/is/are + not + V-ing
(?) Am/Is/Are + S + V-ing ?
(Wh) What/Where... + am/is/are + S + V-ing ?
Time marker: now, right now, at the moment, Look!, Listen!

3. Simple Past Tense

(+) S + V2
(-) S + did not + V1
(?) Did + S + V1 ?
(Wh) Where/Who... + did + S + V1 ?
Time marker: yesterday, last night, ... ago, in 2020, last weekend.

4. Past Continuous Tense

(+) S + was/were + V-ing
(-) S + was/were + not + V-ing
(?) Was/Were + S + V-ing ?
(Wh) What/Where... + was/were + S + V-ing ?
Time marker: at 8 p.m. yesterday, while, when (diselingi Simple Past).
